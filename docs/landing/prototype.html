View release notes ↗

  1. Get the source

    Clone the repository and open the Xcode project.

    git clone https://github.com/jvrviegas/momentum.git
cd momentum
open Momentum.xcodeproj

  2. Build your copy

    Let packages resolve. Choose the Momentum scheme and My Mac, set your signing team for the app and tests if needed, then run with ⌘R.

  3. Make room

    Grant Accessibility access in System Settings. Momentum appears in the menu bar and starts tiling once access is enabled.

ⓘ
A note on compatibility

Only the main display is tiled. Native Desktop integration uses unsupported private macOS APIs and may break after system updates. Direct moves were verified on macOS 27.0.1 with SIP already partially disabled; fully enabled SIP is not yet verified on that build. We do not recommend disabling SIP.

A few things to know

Before you
make the move.

Ask a question ↗
Does Momentum replace Mission Control?

No. Momentum works with native macOS Desktops, keeping a separate tiling layout for each. Desktop destinations follow Mission Control order, exclude fullscreen Spaces, and must already exist on the main display.

Can I use it with multiple displays?

Only the main display is tiled today. Multi-display tiling is not part of the current source preview.

What permissions does it need?

Momentum needs Accessibility access to move, resize, and focus other apps' windows. Enable it under System Settings → Privacy & Security → Accessibility.

Can some windows stay untiled?

Yes. Toggle floating for an individual window or exclude apps in Settings. System Settings is excluded by default. You can also pause automatic tiling from the menu bar.

What should I configure in macOS?

Turn off “Drag windows to screen edges to tile” under Desktop & Dock to avoid competing layouts. For Desktop switching, enable “Switch to Desktop N” under Keyboard → Keyboard Shortcuts → Mission Control. Sending windows does not require those system shortcuts.

What if a Desktop move fails?

Momentum keeps the existing layout intact and shows an error in the menu and Settings. Compatibility can vary with macOS and SIP configuration. Include the error, macOS version, and SIP status when reporting a problem.

Can I configure it with a file?

Yes. Settings live in ~/.config/momentum/tiling.json and reload when edited. Invalid configuration leaves the previous settings active. See the configuration guide for examples.
