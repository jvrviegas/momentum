# Glossary

One name per idea. Buttons, menus, Settings, tooltips, notifications, errors, and docs
use these words and none of the "Not" column. Add a term here before it reaches the UI.

## Voice

Calm, direct, brief. Talk to people as "you". Plain and serious for errors, a little
warmer when a session finishes.

## Flow

| Term | Means | Not |
| --- | --- | --- |
| Flow | The feature that times Flow sessions and breaks | Focus, Focus Timer, Pomodoro, timer |
| Flow session | A timed stretch of focused work | focus session, work session, pomodoro, sprint |
| Break | The countdown that follows a completed Flow session | rest, pause, cooldown |
| Start Flow | Begin a Flow session | Begin, Go, Start Timer |
| Pause / Resume | Stop the countdown and keep the time left / continue it | Hold, Suspend, Continue |
| End Flow | Stop a Flow session early; no break follows | Stop, Cancel, Abort, Finish |
| Skip Break | End a break early | Stop Break, End Break |
| Duration | How long a Flow session, break, or Keep Awake session lasts | length, time, period |

## Keep Awake

| Term | Means | Not |
| --- | --- | --- |
| Keep Awake | Prevent your Mac from sleeping while idle, for a chosen duration | Caffeinate, Stay Awake, Insomnia |
| System only | Keep Awake mode: the Mac stays awake, the display may sleep | system mode |
| System and display | Keep Awake mode: the Mac and the display stay awake | display mode |
| Until stopped | A Keep Awake session with no end time | indefinite, forever |

## Windows

| Term | Means | Not |
| --- | --- | --- |
| Window Tiling | Arranging windows automatically into tiles | layout engine, BSP |
| Retile | Arrange the current windows again | refresh, reflow |
| Floating | A window or app that stays outside tiling | excluded, ignored |
| Focus (left, right, up, down) | Move keyboard focus to the neighboring window. Used only for windows, never for Flow | select, activate |
| Desktop | A native macOS Desktop | Space, workspace |
| Display | A connected screen | monitor, screen |
